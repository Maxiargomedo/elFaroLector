Gestión Masiva de Lista de Precios

Carga masivamente productos desde CSV / Bsale o exporta tu catálogo actual

Instrucciones de Uso

  1. Descarga un respaldo actualizado usando el botón Exportar lista.
  2. Para archivos CSV: Asegúrate de incluir las columnas codigo_barras, nombre y precio. Opcionales: precio_vecino y sku.
  3. Para Bsale: Sube los archivos .xls exportados de Lista Base y Lista Vecino. El sistema los combinará por código de barras.
  4. Elige el modo de importación: Borrar todo y volver a cargar (Recomendado) o Sobrescribir existentes.
